# skill-tracking-system

A web-based Skill Tracking System developed to help users track and manage their skills, courses, assessments, certificates, and learning progress.

## Features

- User login system
- Skill tracking and management
- Course management
- Assessments
- Certificate management
- Communication tests
- Dashboard for tracking progress
- Admin functionality

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

The project contains multiple web pages for different functionalities including:

- Login
- Dashboard
- Courses
- Assessments
- Certificates
- Communication Tests
- Admin Panel

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the main HTML file in a web browser.
